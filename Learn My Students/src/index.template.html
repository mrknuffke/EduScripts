What is a Deck File (.deck.json)?

A Deck File is a self-contained, portable file containing your class roster's extracted photos, student names, and your current memorization box progress.

💾 Save & Back Up Progress Save your deck after studying to preserve Leitner box progress across sessions or computers.
🤝 Easy Roster Sharing Share a .deck.json file with co-teachers, substitutes, or TAs so they can study the photos & names without needing raw PDFs or setup!
⚡ Instant Drag & Drop Drop a saved .deck.json file back into the app anytime to pick up right where you left off.
